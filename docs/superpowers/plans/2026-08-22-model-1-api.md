# Model 1 Registry & GIS API Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (- [ ]) syntax for tracking.

**Goal:** Deliver authorization-scoped Model 1 CCTV registry, GIS, import, audit, export, and reporting APIs backed by PostgreSQL.

**Architecture:** Add a forward-only Model 1 schema, explicit domain and HTTP contracts, scoped Dapper repositories, and focused Minimal API endpoint groups. The service derives GeoJSON coverage sectors and estimated gaps at request time from camera optics and optional area/site boundaries; it never persists a per-camera polygon.

**Tech Stack:** .NET 10, ASP.NET Core Minimal APIs, Dapper, Npgsql, PostgreSQL 17, NetTopologySuite 2.6.0, CsvHelper 33.1.0, xUnit, Shouldly, Testcontainers PostgreSQL.

**Spec:** docs/superpowers/specs/2026-08-22-model-1-api-design.md

## Global Constraints

- Add db/versions/v2_model_1_registry.sql; never edit applied v1.sql.
- PostgreSQL has no PostGIS or other extension requirement.
- Raw credentials must never be stored, logged, audited, or returned.
- Camera coverage polygons are derived on demand from coordinate and optical fields.
- Geographic area and site boundaries are optional GeoJSON Polygon or MultiPolygon values.
- Database queries, including exports and aggregates, enforce organization, geography, and camera-resource scope using federation.has_permission.
- Out-of-scope camera records are omitted from collections and return 404 from item routes.
- Every mutation and its config_audit row share one UnitOfWork transaction.
- Camera removal is soft deactivation. Historical records are preserved.
- Ageing reports require a positive minimumAgeYears query value and do not apply a default threshold.
- CSV is the only import format in this release.
- Run the red-green-refactor cycle for every behaviour; do not add production code before the matching test fails.

public BoundaryParseResult ParseBoundary(string geoJson)
{
    using var document = JsonDocument.Parse(geoJson);
    var type = document.RootElement.GetProperty("type").GetString();
    return type switch
    {
        "Polygon" or "MultiPolygon" => ParsePolygonalBoundary(document.RootElement),
        _ => BoundaryParseResult.Invalid("Unsupported boundary geometry", "Use GeoJSON Polygon or MultiPolygon."),
    };
}

public Geometry CalculateGap(Geometry targetBoundary, IReadOnlyCollection<Geometry> coverageSectors)
{
    var visible = coverageSectors.Count == 0

        : UnaryUnionOp.Union(coverageSectors);

}

public async Task<ImportCommitResult> CommitAsync(Guid batchId, CallerContext caller, CancellationToken ct)
{

    var batch = await GetDraftForCommitAsync(batchId, caller, work, ct);
    var cameras = DeserializeValidatedRows(batch.ValidatedRowsJson);

    foreach (var camera in cameras)
    {
        var id = await _cameras.CreateAsync(camera, caller, work, ct);
        await work.AuditAsync(caller, "create", "camera", id.ToString(), null, camera, camera.OrganizationUnitId, ct);
    }

    await MarkCommittedAsync(batchId, cameras.Count, work, ct);
    await work.CommitAsync(ct);
    return new ImportCommitResult(batchId, cameras.Count, 0, false);
}
~~~

Use CsvHelper’s strict header mapping, a configured byte limit, no formula execution, no credential columns, and a short batch expiry. Re-running a completed batch reads and returns its stored result without another insertion.

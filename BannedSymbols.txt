# APIs banned across the solution.
# Each entry exists because the mistake it prevents is invisible: the code compiles, reads
# correctly at review, and misbehaves only in production. A convention does not hold that
# line across contributors; a compile error does.
# NOTE: no blank lines. The analyzer parses one as an empty symbol and fails with RS0031.
# --- Dapper overloads that silently drop the CancellationToken ---
# Generated from the Dapper assembly rather than hand-written: the analyzer silently ignores
# an ID that does not match a real symbol, so a typo produces a ban that bans nothing.
# Ten call sites had this, three of them on the API-key path that runs on every
# machine-to-machine request.
